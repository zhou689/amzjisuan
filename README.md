# AMZ 运营计算器 2.0

在线使用：https://zhou689.github.io/amzjisuan/

2026-10-22 更新为最新 Excel 转换版，替换旧版页面。

2026-11-03 界面调整：每页表格上方置顶关键结果；新增「原表布局 / 简洁视图」切换（手机默认简洁视图），两种视图共用同一套参数。

包含 FBA 利润、欧洲 FBA、FBM 北美运费、尺寸换算、广告竞价模拟、广告盈亏平衡、选品模板链接与多店铺投入测算，共 8 个页面；另新增第 9 页「头程计算」。

修改参数后即时计算，参数自动保存在当前浏览器。更换电脑时，可使用“导出参数”和“导入参数”迁移；网页没有跨设备自动同步功能。

下载 index.html 或 AMZ运营计算器2.0.html 后，也可离线打开。原表 138 条有效公式已核对，3 处失效引用在页面中标注。

2026-11-03 新增「头程计算」：体积重 = 长×宽×高 ÷ 6000（系数可改），计费重取体积重与实重较大者，乘以海运单价得头程费用；支持按整箱计算后除以箱内件数，并可一键填入 FBA / 欧洲 FBA 的单件头程。

2026-11-04 所有可填写参数默认留空（体积重系数默认 6000），留空按 0 参与计算；“重置本页”改为清空本页参数。

2026-11-04 尺寸换算页改为长/宽/高逐行换算布局，输入与结果同行显示，并汇总长 × 宽 × 高。

2026-11-05 头程计算尺寸支持 cm / inch 切换（inch 按 2.54 折算为 cm 再算体积重），切换时已填尺寸自动换算。
